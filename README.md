# Mini Project - Semester 5

This repository contains the mini project for Semester 5. Follow the instructions below to set up, configure, and run the project.

## Prerequisites
- [Anaconda](https://www.anaconda.com/) installed on your system.
- Clone this repository to your local machine:
  ```bash
  git clone <repository_url>
  ```
- Ensure you have `streamlit` installed in the specified Conda environment.

---

## Setup Instructions

### 1. Activate the Conda Environment
The project uses a Conda environment named `minor_proj`. Activate it using the following command:
```bash
conda activate minor_proj
```
